# Электричество можно понять

**Эллаб** — открытый русскоязычный учебник, где теория сопровождается формулами, графиками, задачами и безопасными виртуальными экспериментами. Цель — подготовить прочную техническую основу для дальнейшего профессионального обучения электротехнике.

**Два прикладных направления:** электрические установки зданий и солнечная энергетика с автономным питанием. **Два рынка:** Германия и Испания.

1. [Первый урок: общая картина](./lessons/00-introduction/) — вводное повествование, которое можно слушать.

5. [Первый безопасный практикум](./practice/01-virtual-circuit/) — проверяем идеи в виртуальной цепи.

## Как мы учимся

Вместо механического запоминания формул: **наблюдение → предположение → объяснение → расчёт → проверка → обсуждение ошибок**.

Каждый урок постепенно развивается в двух форматах: аудиотекст и наглядный учебный конспект. Урок засчитывается, когда можно решить новую задачу и объяснить ограничения своей модели, а не просто дочитать текст.
