# Ellab — интерактивный учебник по электротехнике

Учим электротехнику с нуля до уверенной профессиональной базы для Германии и Испании.

Направления: электрика зданий, солнечная энергетика, автономное питание.

Сайт: Astro Starlight · интерактивные модели · GitHub Pages. Первые уроки и инфраструктура добавляются отдельным коммитом.

> Материалы предназначены для обучения. Практика на действующих сетевых электроустановках требует квалификации и соблюдения применимых правил безопасности.
