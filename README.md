# Эллаб / Ellab

**Интерактивный русскоязычный учебник по электротехнике** — от физических основ к подготовке для работы в Германии и Испании. Два прикладных направления: электрические установки зданий и солнечная энергетика / автономное питание.

## Сайт

После успешной настройки GitHub Pages: https://explesy.github.io/ellab/

Сайт создаётся на Astro + Starlight. Текстовые уроки — Markdown/MDX; интерактивные лаборатории — Astro-компоненты и JavaScript; автоматические тесты проверяют базовые формулы.

## Локальный запуск

~~~bash
npm install
npm run dev
npm test
npm run build
~~~

Для публикации на GitHub Pages: репозиторий → Settings → Pages → **Source: GitHub Actions**. Workflow запускает тесты, сборку и публикацию при изменениях в main. До завершения Actions наличие URL ещё не означает, что сайт опубликован.

## Где что находится

- src/content/docs/lessons/ — учебные темы; вводный текст v1.0 и полный аудиоурок 2 сохранены отдельно.
- src/content/docs/practice/ — безопасные симуляции и учебные эксперименты.
- src/content/docs/reference/ — справочник, карта обучения, профессии.
- src/components/ — интерактивные лаборатории: закон Ома, график I(U), схема цепи и график AC.
- src/lib/electricity.mjs — чистые функции для моделей и тестов.
- tests/ — тесты формул.
- notes/teaching-guidelines.md — правила создания и улучшения уроков.
- notes/archive/ — версии исходных Google Docs на 13 октября 2026 года.

**Личный учебный журнал намеренно не переносится в публичный репозиторий.**

## Рабочий процесс

Новая тема → аудиотекст → схема/формулы → виртуальный эксперимент → самопроверка → исправления через PR. Не перезаписывать архивные редакции: новая версия — отдельный коммит, заметки об изменениях. GitHub Issues — очередь работы, пробелов, ошибок и предложений.

## Безопасность

Учебный проект не выдаёт профессиональную квалификацию. Не проводить самостоятельные эксперименты с сетью 230/400 В, электрощитами и работающими PV-стрингами. Начальные практикумы — симуляторы и защищённые изолированные низковольтные учебные схемы.
